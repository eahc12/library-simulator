📖 도서관 청구기호(KDC) 정렬 비법 가이드

1. 분류기호 정렬 (한국십진분류법 - KDC)

분류기호는 소수점 십진 방식으로 작은 번호부터 정렬합니다.

  • 813.5 (근대소설) < 813.6 (현대소설) < 813.62 < 813.7 (2000년대 이후 소설)
  • 주의: 813.62는 813.6보다 뒤이고 813.7보다 앞입니다.

2. 저자기호 정렬 (엘로드/장서각 방식)

분류기호가 같으면 저자기호의 저자 성씨(가나다순) → 번호(숫자 오름차순) → 도서명 초성(가나다순)으로 정렬합니다.

  • 김19ㄴ (김금희) < 김64ㅅ (김영하) < 김98ㅋ (김훈) < 박14ㅌ (박경리) < 한12ㅊ (한강)

3. 권차(Volume) 및 복본(Copy) 기호

분류기호와 저자기호가 모두 같다면 권차 순서대로 정렬합니다.

  • 단권도서(권차 없음) < v.1 (1권) < v.2 (2권) < v.3 (3권)
